# 即時氣象素材

`background/` 是本次使用者加入的八張 1983×793 氣象背景 PNG，依檔名晴、曇、強風、雨、土砂降り、嵐、雪、吹雪嵌入原生 `.scr`。程式以 WIC 有界解碼，保持完整比例置中於 64% 寬、60% 高區域內，四周純黑；動態資訊由 GDI 與中央玻璃卡合成，不使用已燒錄數值的參考畫面。更換素材時須同步維持或更新此比例契約。

`demo/` 是使用者提供的畫面風格參考；保留在本機並由 `.gitignore` 排除，不編入 `.scr` 或公開安裝程式。

完整資料來源與分類規格見 [即時氣象模式](../../docs/weather-mode.md)。
