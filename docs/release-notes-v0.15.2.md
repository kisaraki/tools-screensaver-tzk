# v0.15.2

氣象資訊面板再縮小約三成面積，改用平滑擬真玻璃。

- 面板背景連續柔化，移除原先的方塊與稀疏取樣質感。
- 加入圓角曲面邊緣折射、細微色散、方向高光、拋光邊及柔和投影。
- 資訊文字移除描邊，改用較乾淨的字體；氣象背景繼續完整置中，四周黑色留白。

79 個程式 tests、34 個安裝政策 checks、24 張離線畫面與非互動 smoke 通過。遠端未執行正式安裝或 UAC；Windows 11 尚未驗證，成品未簽章。
