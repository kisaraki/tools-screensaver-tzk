# tools-screensaver-tzk v0.10.0

日本旅行模式現在包含五種場景。自在飛行、列車旅行、列車駕駛前方及散步模式會在每次啟動與設定的切換時間到期時，重新讀取各自的 YouTube 影片清單並隨機選片；日式旅館維持原有 tw.live 即時來源。

新增「列車駕駛前方」擬真駕駛室，以及中央第一人稱人眼視角的「散步模式」。散步畫面保留寬廣黑色周邊，換片時以 700 ms 上下眼瞼動畫眨眼。

Windows 10 x64 的非互動建置、58 個預設程式測試、19 個安裝判斷測試、52 張 GDI fixture、10 張封鎖網路的 HTML fixture、來源 HTTP probe、smoke 與封裝已通過。成品未簽章；實際 WebView2 播放、多螢幕旅行、安裝／升級／解除安裝與 Windows 11 尚未驗證。
