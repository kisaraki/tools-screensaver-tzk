# tools-screensaver-tzk v0.13.0

- 御運轉士的 16:9 影片現在置中填滿駕駛室窗孔，左右不留黑帶；少量上下裁切限制在窗孔內，不再壓住主題背景。
- 地方散策換片改為清楚的閉眼與睜眼兩段，眼瞼使用橢圓曲線和模糊黑暈，減少筆直銳利感。
- 每次影片載入或重播會從 3:01～8:59 隨機選擇播放起點。
- 在 player ready、load、playing 與字幕 API 狀態變更時主動關閉 YouTube 可切換字幕；來源影片本身燒錄的文字不受 player 控制。
- 全螢幕啟動時先把游標停到主要螢幕外角的非 player 區域，再隱藏游標。
- 移除產品 UI 的舊清單用語。
- 一般 Setup 完成頁可選擇立即開啟「設定」面板，預設勾選；靜默安裝不會開啟 UI。

此版為 Windows 10 x64 未簽章開發候選版。遠端驗證未執行 Setup、UAC、全螢幕或實際 WebView2 播放；詳見 [Phase 20 報告](phase20-report.md)。
