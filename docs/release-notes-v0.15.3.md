# v0.15.3

氣象資訊區玻璃面板更通透：本體遮色不透明度由 30% 減半至 15%，廣域反射強度也減半。保留原本的小面板、平滑背景柔化、圓角曲面折射、高光及文字排版。

79 個預設程式 tests、34 個安裝政策 checks、24 張離線畫面匯出及非互動 smoke 通過。遠端未執行正式安裝或 UAC；Windows 11 尚未驗證，成品未簽章。
