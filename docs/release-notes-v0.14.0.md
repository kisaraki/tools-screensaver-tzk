# v0.14.0：自訂 YouTube 來源與三種桌曆顯示

- 「鐵灰色」顯示名稱改為「鐵灰」，原設定與色值沿用。
- 日本旅行五個場景皆可透過設定面板加入 YouTube 影片或清單連結，每場景最多 10 個；各自保存，與預設來源共同隨機選取。刪除連結可移除來源，清空恢復預設。
- 支援一般影片、分享短網址、Shorts、live、embed 與清單網址；拒絕其他網站與無效 ID。編輯時離線驗證並自動去重；主設定按確定才保存，下次全螢幕啟動套用。
- 桌曆新增「中式」（預設）、「英文」（完整英文月名／星期簡寫）與「日式」（和風月名／七曜日）。全部維持西曆日期與週一首欄，日式不是陰曆換算。
- 設定格式升為 schema 9，保留舊版偏好；新欄位預設中式與空自訂來源。新增欄位一併交易保存，失敗還原。

自訂 YouTube 來源仍受公開性、地區及嵌入限制影響；連結格式正確不代表一定可播放。原有切換時間、不切換、靜音、字幕關閉、隨機播放起點、預抓及失效復原持續適用。
