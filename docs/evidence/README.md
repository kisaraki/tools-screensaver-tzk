# 驗證佐證

本目錄保存 Phase 0～5 的 build、test、PE／resource 檢查、資源觀察與自製 GDI 畫面。各報告記錄當時的工具版本、條件、PASS／NOT TESTED 邊界與成品指紋。

公開 repository 中的文字佐證已將本機使用者名稱、工作目錄、暫存路徑與電腦名稱替換為 `<USERPROFILE>`、`<PROJECT_ROOT>`、`<TEMP>` 與 `test-host`。此處只移除主機識別資訊，不把未執行的測試改成 PASS，也不修改測試數值或成品 hash。

使用者提供的私有視覺參考不在本目錄或 Git repository。PNG fixture 與對話框畫面均由本專案的 renderer 或本專案程式本身產生。
