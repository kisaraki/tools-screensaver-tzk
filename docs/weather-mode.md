# 即時氣象模式

實作版本：v0.15.4；設定 schema 10；日期：2026-09-16。

## 使用方式

主設定選擇「即時氣象模式」，按「氣象城市設定…」。提供臺灣、日本、美國、澳洲、新加坡、中國、英國、法國、德國共 43 個主要城市，預設臺北。

可輸入正式英文城市名（2～80 個 ASCII 字元，接受英文字母、空格、連字號、句點、逗號與撇號）。留空使用預設城市；自訂城市的國家依城市選單所選國家限制。城市搜尋可能有同名結果，採用服務排序後第一個所選國家的結果，畫面顯示實際辨識出的城市名。內層確定更新外層草稿，外層確定才保存；取消不寫入。

「依 IP 約略定位」預設勾選。正式 `/s` 啟動以 HTTPS 連線 [ipwho.is](https://ipwhois.io/documentation) 取得約略城市、國碼與座標；不申請 GPS／Windows 定位權限。VPN、Proxy 或 ISP 出口可能使位置偏離主機所在地。取消勾選即可固定使用設定城市。定位連線失敗或資料無效時回退設定城市，設定城市預設為臺北。

## 氣象來源

| 地區 | 資料 | 備註 |
| --- | --- | --- |
| 臺灣 | 中央氣象署官網測站觀測表 `https://www.cwa.gov.tw/V8/C/W/Observe/MOD/24hr/{station}.html` | 免登入；選取已支援的 15 個測站中最近者；顯示測站名稱，不把測站觀測冒稱城市全境 |
| 其他 | [Open-Meteo Current Weather](https://open-meteo.com/en/docs) | 多國公共氣象機關的模型資料，並非每個城市都有直接測站觀測；資料 CC BY 4.0，介面顯示來源 |
| 自訂城市 | [Open-Meteo Geocoding／GeoNames](https://open-meteo.com/en/docs/geocoding-api) | 按所選國家篩選，編輯時不連網，正式啟動才解析 |

[氣象署官方 Open Data API](https://opendata.cwa.gov.tw/devManual/insrtuction) 需要會員授權碼；本版使用官網公開觀測表，沒有內嵌、借用或要求使用者取得 API key。官網表格結構可能變動，解析失敗會顯示錯誤狀態，不改用其他機關資料冒稱氣象署。

[Open-Meteo 免費端點](https://open-meteo.com/en/pricing) 供非商業使用，沒有免費方案 SLA；商業或大量部署應遵照供應商方案。其開源伺服器授權不會改變本專案 Rust 程式碼的 MIT 授權。

## 更新與畫面

v0.15.2 的玻璃卡邊長為 min(螢幕寬 26%, 背景高度 70%)，相較 v0.15.1 一般面積減少約三成。背景採三次分離模糊近似 Gaussian 擴散；曲面邊緣以平滑取樣位移與細微色散模擬折射，帶有方向性反射、高光、柔和陰影與防鋸齒圓角。文字採乾淨字體且無描邊。畫面與驗證見 [Phase 25](phase25-report.md)。

v0.15.3 將玻璃本體遮色不透明度由 30% 降至 15%（減半），背景透光係數由 0.70 提高至 0.85；廣域反射係數由 0.13 降至 0.065，讓背景更清楚透出。模糊、面板大小、文字及曲面邊緣折射效果保留，見 [Phase 26](phase26-report.md)。

v0.15.4 改為接近全透的清玻璃：本體透光係數 0.98、BGR 色調偏移 [1.34, 1.14, 1.0]，僅保留 2% 遮色不透明度。連續模糊半徑改為 round(面板寬 * 0.006)，限制 1～10px；廣域反射係數 0.018、陰影係數 0.14。背景細節可清楚透出，曲面折射、色散與拋光唇邊仍顯示玻璃光學質感，見 [Phase 27](phase27-report.md)。

- 只有正式全螢幕氣象模式連線；設定預覽、Windows `/p` 與 Debug 靜態畫面不連線。
- 每次 `/s` 重新抓取。單一 coordinator 共享資料給全部螢幕，避免每個螢幕重複請求。
- 請求完成後 60 分鐘再次更新；同一時間最多一組工作。網路工作放在背景，UI timer 只取回結果。
- 資料時間超過兩小時、格式錯誤、資料缺失、HTTP 錯誤或逾時均視為失敗。首次失敗顯示「—°C／無法取得氣象資料」，不捏造數值；後續失敗保留上次資料並明示「更新失敗，保留上次資料」及來源時間。
- 使用 `resources/wpic/background/` 的八張 PNG 保持原始比例縮放至中央 64% 寬、60% 高區域內，四周保留純黑留白。中央資訊卡以背景像素模糊、透光、高光、圓角及陰影合成玻璃效果，顯示城市、攝氏氣溫、天氣、主機時鐘／日期、濕度與風速。圖下顯示來源、定位方式與資料時間。
- `resources/wpic/demo/` 僅為使用者提供的參考示意，不編入程式、不放入公開成品。

## 八類顯示分類

採用 [日本氣象廳雨量門檻](https://www.jma.go.jp/jma/kishou/know/yougo_hp/amehyo.html) 與 [風速門檻](https://www.jma.go.jp/jma/kishou/know/yougo_hp/kazehyo.html) 作為顯示映射基礎。官方警報有地域條件；「嵐、吹雪」並無適用全球的單一官方數值界線，本版是畫面分類，不發布或推定官方警報。

依以下優先序選取一張背景：

| 優先序 | 畫面 | 條件 |
| ---: | --- | --- |
| 1 | 吹雪 | 下雪且風速 ≥10 m/s；這是程式視覺推定，非 JMA 暴風雪警報 |
| 2 | 嵐 | 風速 ≥20 m/s，或天氣代碼為雷暴；程式的強烈天氣分類 |
| 3 | 雪 | WMO 71～77、85、86，或 CWA 現象包含雪 |
| 4 | 土砂降り | 過去／模型一小時雨量 ≥20 mm；保留使用者指定名稱，JMA 對 20～30 mm/h 使用「強い雨／どしゃ降り」 |
| 5 | 強風 | 風速 ≥15 m/s |
| 6 | 雨 | 降水天氣代碼或一小時雨量 >0 |
| 7 | 曇 | 多雲、陰、霧等 |
| 8 | 晴 | 晴或大致晴朗 |

臺灣一小時雨量由連續七筆、每十分鐘的當日累積雨量差值加總；遇到缺筆、不連續或缺值時不以累積值判定豪雨。跨午夜將新一天累積值作為重置後差值。全球則使用對應目前小時的 Open-Meteo hourly rain。模型風速與測站平均風速有不同採樣方式，分類不能代替防災資訊。

## 設定契約與網路邊界

HKCU `Software\tools-screensaver-tzk`：`WeatherAutoLocation`、`WeatherCityIndex` 為 DWORD；`WeatherCustomCity` 為 canonical English UTF-8 REG_BINARY。城市索引採附加方式擴充，不能重排既有項目。schema 9 以下忽略新欄位，schema 10 倒數保存不得清除氣象或自動更新設定；未來 schema 不可覆寫。

WinHTTP 僅允許固定 HTTPS host，不跟隨 redirect；一般回應上限 512 KiB、單次 I/O 5 秒、body 讀取總上限 20 秒。URL 中的自訂城市逐 byte percent-encode；JSON／HTML 只作有界資料解析，永不執行腳本。定位服務會看到連線來源 IP；氣象服務會收到座標，城市搜尋會收到輸入名稱。README 與設定面板均提供揭露。
