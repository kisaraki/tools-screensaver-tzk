# v0.15.0

新增「即時氣象模式」與使用者可選的版本更新。

- 氣象模式使用八種像素風背景及中央玻璃資訊卡。臺灣採中央氣象署測站觀測，其他地區採 Open-Meteo 目前天氣模型。
- 提供九個國家／地區的 43 個主要城市、正式英文自訂城市與 IP 約略定位；定位失敗回退設定城市，預設臺北。
- 每次正式啟動抓取氣象，每小時更新；多螢幕共享結果。顯示來源與資料時間，失敗明示狀態，不填造數值。
- 設定面板新增「自動更新」（預設關閉）及「手動更新」。啟用後每天首次未鎖定啟動檢查正式版本；發現新版詢問使用者，確認後核對下載 SHA-256 再啟動一般 Setup。
- 設定 schema 10 保存新偏好；保留桌曆、番茄鐘及五種日本旅行場景與自訂 YouTube 來源。

79 個預設 Rust tests、19＋15 個安裝政策 checks、24 張氣象離線畫面、原生公開氣象與更新下載探測及非互動 smoke 通過。遠端驗證未啟動安裝／UAC；實際 UI、氣象長時間刷新及更新重裝仍需在本機補測。Windows 11 尚未驗證，成品未簽章。氣象背景分類不等同官方防災警報。

[公開下載頁](https://kisaraki.github.io/tools-screensaver-tzk/)。SCR、Setup 與 SHA256SUMS 不需要 GitHub 帳號。

完整實作、來源與測試證據見 [Phase 23](phase23-report.md)、[氣象規格](weather-mode.md)、[更新規格](automatic-updates.md)。
