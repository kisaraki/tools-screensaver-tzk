# tools-screensaver-tzk v0.8.0

- 鐘面 12／3／6／9 縮小約 25%，稍向內移，與刻度保留間距。
- 「自在飛行」與「列車旅行」改用內附原創 AI 擬真圖像；設定與離線預覽也使用相同圖像。場景為虛構，並非特定機型或列車的照片。
- 設定新增旅行來源切換時間：預設每 1 分鐘，可選 1～1440 分鐘或「不切換」。不切換會停止定時換景，但仍保留來源故障復原。
- 保留每個螢幕獨立播放、城市／狀態顯示與來源輪換。
